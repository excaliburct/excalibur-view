PLUGINS CAN HAND YOU A FILE

A plugin can now offer a file to save: a takeoff for an estimating program,
or a report. It still writes nothing itself. Each file it offers gets a Save
button in the plugin's results, and Excalibur View writes it only where you
choose in the save box.

A plugin may only offer plain data files: a plain file name, at most 16 MB,
and never a program, a script, a shortcut, a web page or one of Excalibur
View's own trusted files (plugins, licenses, tool chests). A file that breaks
these rules gets no Save button, and the window says why.

Plugins are also told where and when they are being run: this program's
version, who is running it, the office project and drawing set the drawing
came from, and the time. That lets a file a plugin writes say where it came
from.

Nothing else changes for a plugin. It is still sandboxed: no files, no
network, no clock of its own. It is still signed, and it still runs only when
somebody runs it.

Tool chests can be checked before they are shared. A program that writes
tool chests can run them through Excalibur View's own import with
chest::native::check. It names every tool the import would leave out, every
colour it would change and every column it would drop, where the import alone
passes over them without a word.

Nothing needs doing.
